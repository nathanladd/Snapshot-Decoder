Welcome to Snapshot Decoder

Snapshot Decoder is a powerful diagnostic tool for analyzing Bobcat Engine Analyzer (BEA) snapshot files. It helps Bobcat techs visualize and interpret diagnostic snapshots to quickly identify issues.

Quick Start: Open a snapshot file using File → Open Snapshot or press Ctrl+O.
Save complete snapshots: When capturing a snapshot in Bobcat Engine Analyzer, always save all PIDs possible – never a subset. Snapshot Decoder can only correctly identify and process complete snapshot files. Files saved with only a selection of PIDs are missing information Snapshot Decoder needs to detect the snapshot type, and will fail identification. See Opening Files for details.

Key Features

  • Multi-format Support - Load V1 ECU, V1 Engine Use Data, and ECU V2 snapshot formats
  • Quick Charts - One-click diagnostic Quick Charts for common diagnostics
  • Custom Charting - Quickly search PIDs by description to create custom line charts
  • Powerful Chart Views - Zoom, pan, and compare actual PID values with time converted to minutes and seconds
  • Chart Cart - Export single or multiple charts to PDF for documentation
