Keyboard Shortcuts

Use these keyboard shortcuts to work more efficiently with Snapshot Decoder.

File Operations

ShortcutAction
Ctrl + OOpen snapshot file
Ctrl + WClose snapshot
Ctrl + QExit application

View Options

ShortcutAction
F1Open Help
Ctrl + Shift + DRestore default view layout

Chart Commands

ShortcutAction
Ctrl + Shift + HHome (reset chart view)
Ctrl + Shift + PPan
Ctrl + Shift + ZZoom
Ctrl + Shift + SSave chart as PDF
Ctrl + Shift + CAdd to Chart Cart
Ctrl + Shift + VToggle value display
Ctrl + Shift + TToggle time slider
Ctrl + Shift + EToggle separate charts
Ctrl + Shift + QOpen Quick IQ
Ctrl + PPop out chart to separate window

Mouse Actions

ActionFunction
Left-Click + DragPan chart (when pan tool active)
Right-Click + DragZoom chart (when pan tool active)
Click + Drag RectangleZoom to area (when zoom tool active)
