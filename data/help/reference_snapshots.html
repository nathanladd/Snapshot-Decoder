Reference Snapshots

Reference snapshot data is captured in a standardized manner to make comparison to known-good machines easier.

Bobcat made a series of reference snapshots by choosing pre-retailed machines with no prior known issues. If a snapshot is obtained on a suspect machine in an identical manner as to the way the data was collected on the reference machine in this knowledge article, commonly reviewed engine related parameters can be compared to assess if a problem exists.

Warm-up Procedure

Before acquiring a snapshot, reference machines were run at high idle for approximately 10 minutes to warm up before being shut off. "Warm" was defined as:

  • Coolant temperature (V2 BEA parameter 23) = approximately 180°F
  • Oil temperature (V2 BEA parameter 157) = approximately 140°F

Snapshot Acquisition Procedure

Once the machine was warm, and while utilizing a stopwatch, the following procedure was followed:

  1. Started acquiring the snapshot in BEA and waited 5 seconds
  2. Started the engine and ran at low idle for 25 seconds
  3. Ran the engine at high idle for 30 seconds
  4. Ran the engine at high idle with the auxiliaries run over relief for 30 seconds
  5. Ran the engine at high idle for 30 seconds
  6. Ran the engine at low idle for 30 seconds
  7. Stopped the engine and continued recording for 30 seconds before stopping the snapshot

Important Notes:

  • Following this exact procedure ensures that your snapshot data will be comparable to the reference data
  • The timing is critical - use a stopwatch to maintain accurate intervals
  • Make sure the machine is properly warmed up before beginning the procedure
  • Temperature targets should be reached before starting the snapshot acquisition

Comparison Guidelines:

When comparing your snapshot to reference data, focus on:

  • Parameter trends during each phase of the procedure
  • Temperature response patterns
  • Pressure behavior during idle and high idle operations
  • Auxiliary system performance during relief testing
